# Placeholder imagery

**Every image in this directory is AI generated. None of it is a photograph of
Art's Place, and none of it should ship to production.**

## Why it exists

Three design directions had to be shown to the restaurant before their own photo
collection arrived. Empty layouts read as unfinished in a way that has nothing to do
with the design, so these stand in.

## The rules they were made under

- Only dishes that are **actually on the menu**, plus room and atmosphere. No image
  depicts a dish the kitchen does not serve. (An earlier AI build shipped an "Osso
  Buco" photo for a dish that has never been on the menu.)
- Files are named for **what the image shows**, not for the dish it stands in for. The
  pasta shot reads as marinara rather than the real half-and-half, so it is named
  `pasta-marinara`, not `spaghetti-half-and-half`.
- **No generated image of Art Ibleto.** A real photograph of him exists, and inventing
  a picture of a real person who has died is not something we do.
- Everything is isolated here rather than sitting alongside real assets, so nothing
  can be mistaken for the restaurant's own photography.

## When real photos arrive

Delete this directory and drop the real files into the same slots. The layouts were
built to accept them without redesign.

Generated with FLUX1.1 Pro via Zero, August 2026.
